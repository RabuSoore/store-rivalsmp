Tutorial

Register & Login

1

Untuk pemain baru, gunakan command:

/register (password) (password)

Contoh: /register rahasia123 rahasia123

2

Untuk login kembali, gunakan:

/login (password)

Contoh: /login rahasia123

Jangan bagikan password kepada siapapun, termasuk admin!

Login Bedrock

1

Buka Minecraft Bedrock Edition

2

Pilih "Servers" lalu "Add Server"

3

Masukkan data server:

IP: mc.rivalsmp.my.id
Port: 19132
4

Klik "Play" untuk bergabung

Pastikan koneksi internet stabil untuk pengalaman bermain terbaik

Beli Rank

1

Buka halaman Rank di website ini

2

Pilih rank yang diinginkan

3

Klik "Lihat Fitur" untuk melihat detail rank

4

Klik "Beli Sekarang" untuk lanjut ke WhatsApp

Admin akan merespon dalam 1x24 jam setelah pembayaran

Beli Coin

1

Buka halaman Coin di website ini

2

Pilih paket coin yang diinginkan

3

Klik "Beli Sekarang" untuk lanjut ke WhatsApp

4

Lakukan pembayaran sesuai instruksi admin

Coin akan langsung ditambahkan setelah pembayaran diverifikasi
